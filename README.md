# SkillCore Demo (Windows)

Free playable demo of SkillCore, a skill tree system for Unreal Engine 5.8.

Download `SkillCore_Demo_Win64_v1.1.zip` from [Releases](https://github.com/enquel/SkillCore-Demo/releases/latest), unzip, run `SkillCoreDemo.exe`. Windows 10/11 64-bit, no install or account.

Three skill trees (Warrior, Tech Lab, Survivor; 23 skills), two point pools, skill ranks, refunds and tree respec, a tier gate, a choose-one pair, XP levels that give points, a ready-made tree screen with pan and zoom, mouse, keyboard and gamepad.

Documentation: https://enquel.github.io/SkillCore-docs/
