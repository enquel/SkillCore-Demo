# SkillSet Demo (Windows)

Free playable demo of SkillSet, a skill tree system for Unreal Engine 5.8.

Download `SkillSet_Demo_Win64_v1.2.zip` from [Releases](https://github.com/enquel/SkillSet-Demo/releases/latest), unzip, run `SkillSetDemo.exe`. Windows 10/11 64-bit, no install or account.

Three skill trees (Warrior, Tech Lab, Survivor; 23 skills), two point pools, skill ranks, refunds and tree respec, a tier gate, a choose-one pair, XP levels that give points, a ready-made tree screen with pan and zoom, mouse, keyboard and gamepad. The demo is single-player; the plugin itself also has server-authoritative multiplayer and a graph editor for building trees.
